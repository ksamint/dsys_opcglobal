Icon-only square button for toolbars, dialog close, and dense rows; the label is mandatory.

```jsx
<IconButton label="Close"><Icon name="x" /></IconButton>
<IconButton label="Search" variant="secondary"><Icon name="search" /></IconButton>
<IconButton label="Menu" variant="inverse"><Icon name="menu" /></IconButton>   // on navy
<IconButton label="Bookmark" selected><Icon name="bookmark" /></IconButton>
```
