## Initial snapshot

Seeded from [ksamint/tableai_designaha](https://github.com/ksamint/tableai_designaha/tree/17e8486df5cc2896049164fdef9c876e5790897b/OPCGLOBAL) at `17e8486df5cc2896049164fdef9c876e5790897b` and the published brand API. Existing tracked brand files retain their original paths. This is the current foundation; incomplete brand guidelines remain incomplete.

Official media remains at the URLs in `data/assets.json`; checksums identify the exact assets. Only files already tracked in the source repository were copied. Local ignored and private files were not imported.

Future design-system work can evolve here independently. The IPTrust catalog links to this repository; this initial import does not enable automatic synchronization back to the catalog. Consult [apuch.art](https://apuch.art/) and its brand API for the latest published brand guidance.
